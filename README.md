# WhatsApp Status Bot – Auto View, React & Download 🚀

A **professional WhatsApp Status Automation Bot** built with **Node.js and Baileys**.  
Automatically **view**, **react**, **reply**, and **download WhatsApp statuses** with a **real-time dashboard** and **anti-ban protection**.

---

## 🔍 Keywords (SEO)
WhatsApp bot, WhatsApp status bot, WhatsApp automation, Baileys bot, Node.js WhatsApp bot, auto view status, auto react WhatsApp, WhatsApp dashboard bot

---

## 🌟 Key Features

- 📱 Phone number pairing (No QR)
- 👁️ Auto status viewing
- ❤️ Emoji auto reactions (custom & random)
- 💬 Optional auto replies
- 🛡️ Anti-ban protection system
- 📈 Live dashboard (Express + Socket.IO)
- 📥 Status image & video downloader
- 💬 WhatsApp command-based control

---

## 🛠️ Tech Stack

- Node.js
- Baileys (WhatsApp Web API)
- Express.js
- Socket.IO
- HTML, CSS, JavaScript

---

## 📦 Installation

```bash
git clone https://github.com/Dev-ixAAr/whatsapp-status-bot.git
cd whatsapp-status-bot
npm install
```

---

## ⚙️ Configuration

```bash
cp config.example.js config.js
```

Edit `config.js` with your settings.

---

## ▶️ Run

```bash
npm run
```

Dashboard:
```
http://localhost:3000
```
